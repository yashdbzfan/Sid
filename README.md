# Neurosurgeon CV website

A responsive, multi-page professional CV site. It works as a static website and requires no build tools or dependencies.

## Preview

Open `index.html` in a browser. The section pages are `appointments.html`, `education.html`, `research.html`, and `publications.html`. Keep all files together; relative links and shared assets expect the same directory. The site also works from a basic static host.

## Personalize before publishing

- Replace every bracketed field with verified professional information.
- Replace the sample image with an approved, properly licensed professional photograph, or remove the image panel.
- Replace the publication examples with real citations and verified DOI or PubMed links. Do not publish placeholder records.
- Replace the contact dialog's Gmail and mobile placeholders with approved contact details before publishing.
- Add an accessible, tagged PDF CV if you have one; the current button uses the browser print dialog and can save this page as PDF.
- Confirm institutional naming and affiliation policies, medical advertising requirements, and any required compliance review.
- Use official hospital channels for patient care and referrals. Do not collect patient details or publish patient information, testimonials, or case details here.
- Replace the contact placeholder with a professional address and warn correspondents not to send health information by email.

## Features

- Responsive navigation with keyboard-accessible mobile menu.
- Separate pages for appointments, education, research, and publications; the homepage profile remains on `index.html`.
- Expandable appointment and training entries using native `<details>` elements.
- Expand-all and collapse-all controls for appointment and training timelines.
- Client-side publication search and year filter.
- Print stylesheet and browser print-to-PDF control.
- Reduced-motion support, visible focus states, skip link, and semantic landmarks.

The medical disclaimer is general information, not legal advice. Have the appropriate institutional or legal reviewers approve the site before launch.
